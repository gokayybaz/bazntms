01Genel Bakış

bazNTMS bugün tek makinede çalışan bir monolittir: paket yakalama, SQLite kayıt, uyarı motoru, AI analizi, GeoIP, PCAP kaydı, rapor ve gömülü dashboard tek binary'nin içinde. Enterprise hedefi, bu yetenekleri merkezi hub + uç agent + ağ cihazı entegrasyonları üçlüsüne genişletmek ve 1.000 cihaz / 5.000 agent ölçeğinde çoklu-siteli, hibrit dağıtılabilir bir izleme platformuna dönüştürmektir. Mevcut kodun tamamı hub tarafına taşınır — atılan hiçbir iş yoktur. Her faz shippable dikey dilim olarak tasarlanmıştır: faz sonunda demo edilebilir bir artış vardır.

FAZ 2Derin Telemetri: Süreç Bazlı Trafik 4-6 hafta

FAZ 2

Kim, Hangi Süreçle, Nereye Bağlanıyor

4-6 hafta

"Tam yetenek" hedefinin kalbi: platform başına en derin toplama yöntemi, düşük kernel/sürümde graceful degrade ile.

Linux — eBPF

  • cilium/ebpf; socket bazlı byte/paket → PID eşleme
  • CAP_BPF / CAP_PERFMON; min kernel 5.8 matrisi
  • Düşük kernel → Faz 1 telemetrisine otomatik degrade

Windows — ETW / WFP

  • Kernel-Network provider (ETW) veya WFP callout; cgo binding
  • SYSTEM servis; AV/SmartScreen için imzalı binary zorunlu

macOS — kademeli

  • Faz 1 telemetrisi + opsiyonel BPF yakalama yeterli
  • Endpoint Security ağ uzantısı ileri faz (notarization maliyeti)

Opsiyonel PCAP

  • Mevcut record.go agent'ta yeniden kullanılır
  • Policy ile açılır; hub'dan "şimdi kaydet"; ring-buffer limitli

Veri Modeli

process_traffic(ts, agent, pid, process, exe_hash, remote_ip, port, proto, bytes_in, bytes_out) — süreç bazlı top-talker ve anomali tespiti bu tablonun üstüne kurulur.

Süreç bazlı gerçek trafik sayaçları — "kim ne kadar veri transfer etti" sorusunun kesin cevabı

05Kapasite Hedefleri (Faz 4 Doğrulama Kriterleri)

Cihaz Poll

  • 1.000 cihaz, 60 sn poll döngüsü
  • SNMPv3 timeout/retry bütçesi: poll döngüsü %80'i aşmaz
  • Cihaz başına ~40 OID grubu

Agent Telemetri

  • 5.000 agent, 30 sn batch
  • Batch başına ~50-150 KB (sıkıştırmalı)
  • Ingest: ≥170 istek/sn sürekli

Flow İşleme

  • ≥50.000 flow/sn sürekli
  • Burst: 200K flow/sn, 5 dk kayıpsız (NATS buffer)

Depolama

  • Ham telemetri 7 gün, 1dk agregasyon 90 gün, 1sa 2 yıl
  • Query p95 < 1 sn (24 saatlik panel)
